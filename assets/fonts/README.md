# Tipografia SOMA

Arquivos TTF estáticos de Sora 600 e Manrope 400/600, obtidos do serviço oficial Google Fonts. O aplicativo carrega esses arquivos locais com `expo-font`, sem requisição externa de fontes. As licenças SIL Open Font License estão neste diretório.

`fontes-origem.css` registra as URLs e os pesos que originaram os arquivos. Sora é usada em títulos e assinatura; Manrope em leitura e controles. Caso o carregamento falhe, o aplicativo usa a fonte do sistema e continua disponível.
